RETURNS

The DRT classified as MAIN_EXECUTION_DRT.

Returns UNKNOWN when no general execution DRT can be identified.

Returns UNKNOWN when more than one DRT satisfies the definition.

PROCESS.RT_NAME IDENTIFIES THE RESPONSIBLE TECHNICAL PROFESSIONAL WHO SUBMITTED
THE ADMINISTRATIVE REQUEST.

MAIN_EXECUTION_DRT IDENTIFIES THE PROFESSIONAL RESPONSIBLE FOR THE EXECUTION
COVERED BY THAT DRT.

THE IDENTITY BETWEEN PROCESS.RT_NAME AND
MAIN_EXECUTION_DRT().RT_NAME SHALL NOT BE USED AS A DOCUMENTARY VALIDATION
CRITERION UNLESS AN EXPLICIT NORMATIVE REQUIREMENT ESTABLISHES SUCH IDENTITY.

DRT_COVERS RETURNS TRUE ONLY WHEN THE DRT EXPLICITLY COVERS THE DOCUMENT, SMSCI AND REQUIRED ACTIVITY.

DRT_SET_COVERS_ALL RETURNS TRUE WHEN ONE GENERAL DRT EXPLICITLY COVERS ALL SMSCI OR WHEN THE UNION OF DRT SCOPES COVERS ALL SMSCI.

ALL_DRT_HAVE_ACTIVITY RETURNS TRUE ONLY WHEN EACH DRT USED AS EVIDENCE DECLARES THE REQUIRED ACTIVITY.

HAS_DRT_ACTIVITY ACCEPTS ONE OR MORE DRTS, INCLUDING ONE DRT WITH MORE THAN ONE EXPLICIT ACTIVITY.

VALID_WITHIN_YEARS RETURNS UNKNOWN WHEN THE ISSUE DATE CANNOT BE VERIFIED.

REPORT_CONTAINS RETURNS TRUE ONLY WHEN ALL REQUIRED ITEMS ARE IDENTIFIED IN THE REPORT.

REPORT_PREPARED_BY_INDEPENDENT_PARTY RETURNS UNKNOWN WHEN INDEPENDENCE CANNOT BE VERIFIED FROM THE SOURCES.

RESPONSIBILITY_EVIDENCE_PROFESSIONAL_REGULARITY RETURNS FALSE ONLY WHEN A
DOCUMENTARY FACT IDENTIFIES THE DRT AS PROFESSIONALLY IRREGULAR.

RESPONSIBILITY_EVIDENCE_PROFESSIONAL_REGULARITY RETURNS TRUE WHEN THE DRT IS
EMITTED IN SC AND NO PROFESSIONAL IRREGULARITY IS DOCUMENTED.

RESPONSIBILITY_EVIDENCE_PROFESSIONAL_REGULARITY RETURNS MANUAL_REVIEW WHEN THE
DRT IS EMITTED BY A COUNCIL FROM ANOTHER UF, OR WHEN COUNCIL_STATE CANNOT BE
DOCUMENTALLY IDENTIFIED, REGARDLESS OF RESPONSIBILITY_TYPE. THIS RESULT DOES NOT CREATE A NONCONFORMITY OR A FAIL.

THE MANUAL_REVIEW RESULT APPLIES EQUALLY TO EXECUTION DRTS AND DRTS OF OTHER
NATURES.

RESPONSIBILITY_EVIDENCE_MATCHES_PROCESS_RI_LEGAL_ENTITY RETURNS FALSE ONLY
WHEN DOCUMENTARY EVIDENCE IDENTIFIES THE RESPONSIBLE PARTY IN THE EVIDENCE
DOCUMENT AND THE RESPONSIBLE PARTY IN THE PROCESS AS DISTINCT LEGAL PERSONS.

FOR LEGAL PERSONS, A DIFFERENCE BETWEEN THE CNPJ IN THE PROCESS AND THE CNPJ
IN THE EVIDENCE DOCUMENT, BY ITSELF, DOES NOT IDENTIFY DISTINCT LEGAL PERSONS
AND SHALL NOT PRODUCE A FAIL. THIS INCLUDES CNPJS OF THE HEAD OFFICE AND OF A
BRANCH OF THE SAME LEGAL PERSON.

RESPONSIBILITY_EVIDENCE_MATCHES_PROCESS_RI_LEGAL_ENTITY RETURNS TRUE WHEN THE
DOCUMENTARY EVIDENCE IDENTIFIES THE SAME LEGAL PERSON, INCLUDING A HEAD OFFICE
AND ITS BRANCH, OR WHEN THE CNPJ DIFFERENCE IS THE ONLY AVAILABLE EVIDENCE.

RESPONSIBILITY_RT_MATCHES_PRODUCT RETURNS FALSE ONLY
WHEN THE RESPONSIBLE TECHNICAL PROFESSIONAL IDENTIFIED IN THE DRT IS DIFFERENT
FROM THE RESPONSIBLE TECHNICAL PROFESSIONAL IDENTIFIED IN THE TECHNICAL
PRODUCT THAT SATISFIES THE SAME REQUIRED TECHNICAL RESPONSIBILITY.

RESPONSIBILITY_RT_MATCHES_PRODUCT RETURNS TRUE WHEN
THE SAME RESPONSIBLE TECHNICAL PROFESSIONAL IS IDENTIFIED IN BOTH THE DRT AND
THE TECHNICAL PRODUCT THAT SATISFIES THE SAME REQUIRED TECHNICAL
RESPONSIBILITY.

RESPONSIBILITY_RT_MATCHES_PRODUCT RETURNS NOT_APPLICABLE WHEN
NO TECHNICAL PRODUCT IS REQUIRED BY THE KNOWLEDGE BASE FOR THAT RESPONSIBILITY.

RESPONSIBILITY_RT_MATCHES_PRODUCT RETURNS UNKNOWN WHEN
THE TECHNICAL PRODUCT THAT SATISFIES THE SAME REQUIRED TECHNICAL
RESPONSIBILITY DOES NOT IDENTIFY THE RESPONSIBLE TECHNICAL PROFESSIONAL OR
WHEN THE COMPARISON CANNOT BE PERFORMED FROM THE DOCUMENTARY EVIDENCE.

THIS FUNCTION SHALL NOT COMPARE THE RESPONSIBLE TECHNICAL PROFESSIONAL
IDENTIFIED IN THE DRT WITH THE RESPONSIBLE TECHNICAL PROFESSIONAL WHO
SUBMITTED THE ADMINISTRATIVE REQUEST.

THE COMPARISON IS RESTRICTED TO THE DRT AND THE TECHNICAL PRODUCT THAT
SATISFIES THE SAME REQUIRED TECHNICAL RESPONSIBILITY.

WHEN THE REQUESTED EVIDENCE ATTRIBUTE IS SIGNED,

THE VALIDATION SHALL SEARCH ONLY FOR DOCUMENTALLY VERIFIABLE DIGITAL OR
ELECTRONIC SIGNATURES.

THE FOLLOWING SHALL BE ACCEPTED AS DOCUMENTALLY VERIFIABLE DIGITAL OR
ELECTRONIC SIGNATURES:

- ICP-BRASIL DIGITAL SIGNATURES;
- PADES DIGITAL SIGNATURES;
- ELECTRONIC SIGNATURES ISSUED BY CREA;
- ELECTRONIC SIGNATURES ISSUED BY CAU (SICCAU);
- ELECTRONIC SIGNATURES ISSUED BY CFT;
- OTHER DIGITAL AUTHENTICATION MECHANISMS EXPLICITLY IDENTIFIED IN THE
DOCUMENT.

TECHNICAL_PRODUCT_ATTRIBUTE RETURNS TRUE WHEN A DOCUMENTALLY VERIFIABLE
DIGITAL OR ELECTRONIC SIGNATURE IS IDENTIFIED.

TECHNICAL_PRODUCT_ATTRIBUTE RETURNS MANUAL_REVIEW WHEN NO DOCUMENTALLY
VERIFIABLE DIGITAL OR ELECTRONIC SIGNATURE CAN BE IDENTIFIED FROM THE
DOCUMENTARY EVIDENCE.

THE ABSENCE OF A DOCUMENTALLY VERIFIABLE DIGITAL OR ELECTRONIC SIGNATURE
SHALL NOT, BY ITSELF, PRODUCE FALSE.

# EXECUTION MODEL
###############################################################################

FOR EACH CRITERION

SET ASSERT_RESULT = TRUE

    IF APPLIES_TO IS NOT PRESENT IN PROCESS.SMSCI

        REGISTER RESULT NOT_APPLICABLE
        REGISTER CRITERION
        REGISTER REQUIREMENT
        CONTINUE

    END

    FOR EACH VALIDATE DECLARED IN THE ACTIVE REQUIREMENT

        EXECUTE THE CORRESPONDING VALIDATION FUNCTION

        IF ANY VALIDATION RETURNS FALSE

            SET ASSERT_RESULT = FALSE

        ELSE IF ANY VALIDATION RETURNS MANUAL_REVIEW

            SET ASSERT_RESULT = MANUAL_REVIEW

        ELSE IF ANY VALIDATION RETURNS UNKNOWN
            AND ASSERT_RESULT IS NOT FALSE

            SET ASSERT_RESULT = UNKNOWN

        END

    END

    IF ASSERT_RESULT IS NOT FALSE
       AND ASSERT_RESULT IS NOT MANUAL_REVIEW

        EXECUTE ASSERT
        
        IF ASSERT RETURNS FALSE

    SET ASSERT_RESULT = FALSE

ELSE IF ASSERT RETURNS MANUAL_REVIEW
    AND ASSERT_RESULT IS NOT FALSE

    SET ASSERT_RESULT = MANUAL_REVIEW

ELSE IF ASSERT RETURNS UNKNOWN
    AND ASSERT_RESULT IS TRUE

    SET ASSERT_RESULT = UNKNOWN

END

    END

    IF ASSERT_RESULT = TRUE

        REGISTER RESULT TRUE
        REGISTER CRITERION
        REGISTER REQUIREMENT
        REGISTER DOCUMENT_EVIDENCE

    ELSE IF ASSERT_RESULT = FALSE

        REGISTER RESULT FALSE
        REGISTER CRITERION
        REGISTER REQUIREMENT
        REGISTER DOCUMENT_EVIDENCE
        REGISTER NONCONFORMITY FROM FAIL

    ELSE IF ASSERT_RESULT = MANUAL_REVIEW

        REGISTER RESULT MANUAL_REVIEW
        REGISTER CRITERION
        REGISTER REQUIREMENT
        REGISTER DOCUMENT_EVIDENCE
        REGISTER OPERATIONAL_ALERT FROM MANUAL_REVIEW

    ELSE

        REGISTER RESULT UNKNOWN
        REGISTER CRITERION
        REGISTER REQUIREMENT
        REGISTER DOCUMENT_EVIDENCE

    END

END
