ENTITY DRT

TYPE DOCUMENT

ATTRIBUTE COUNCIL_STATE TEXT

ATTRIBUTE RESPONSIBILITY_TYPE ENUM

ATTRIBUTE PROFESSIONAL_REGULARITY ENUM

DESCRIPTION

COUNCIL_STATE identifica a UF do conselho profissional emissor da DRT.
RESPONSIBILITY_TYPE registra a natureza declarada na DRT.
PROFESSIONAL_REGULARITY registra o resultado documental da verificação de
regularidade profissional: REGULAR, IRREGULAR ou MANUAL_REVIEW.

Esses atributos qualificam exclusivamente a validade documental da DRT na
Tabela 1; não criam uma nova responsabilidade técnica.

END

# ESCOPO DA DRT
###############################################################################

ENTITY DRT_GENERAL_SCOPE

TYPE CONCEPT

DESCRIPTION

Objeto técnico de execução com abrangência sobre todos os
sistemas e medidas preventivos contra incêndio e pânico,
excetuados apenas aqueles cuja legislação exige documento
ou responsabilidade técnica específica.

MATCH

"SISTEMAS E MEDIDAS PREVENTIVOS CONTRA INCÊNDIO E PÂNICO"

MATCH

"PREVENÇÃO E COMBATE A INCÊNDIO E PÂNICO"

MATCH

"SISTEMA PREVENTIVO CONTRA INCÊNDIO"

MATCH

"EXECUÇÃO DOS SISTEMAS PREVENTIVOS"

END

# CLASSIFICAÇÃO FUNCIONAL DAS DRT
###############################################################################

ENTITY MAIN_EXECUTION_DRT

TYPE DRT

DESCRIPTION

Estrutura legada de classificação documental para DRT que assume a
responsabilidade global pela execução dos sistemas e medidas preventivos
contra incêndio e pânico da edificação.

RULE

É identificado quando o objeto técnico possuir abrangência compatível
com DRT_GENERAL_SCOPE.

END

ENTITY COMPROVANTE_DE_SOLICITACAO_DE_HABITESE

TYPE DOCUMENT

ATTRIBUTE REQUEST_IDENTIFIER TEXT

ATTRIBUTE PROCESS_IDENTIFIER TEXT

ATTRIBUTE PROTOCOL_IDENTIFIER TEXT

NAME

COMPROVANTE DE SOLICITAÇÃO DE HABITE-SE

DESCRIPTION

Comprovante documental de uma solicitação de Habite-se. Os identificadores
registrados são fatos documentais e permitem somente sua posterior vinculação
à solicitação corrente; não determinam aplicabilidade.

END

-------------------------------------------------------------------------------

ENTITY SISTEMAS_E_MEDIDAS_DE_SEGURANCA

TYPE DOCUMENT_SECTION

ATTRIBUTE STRUCTURALLY_COMPLETE BOOLEAN

ATTRIBUTE LEGIBLE BOOLEAN

ATTRIBUTE VERIFIABLE BOOLEAN

NAME

SISTEMAS E MEDIDAS DE SEGURANÇA

DESCRIPTION

Seção documental "Sistemas e Medidas de Segurança" do comprovante de
solicitação de Habite-se. STRUCTURALLY_COMPLETE, LEGIBLE e VERIFIABLE registram
somente propriedades documentais diretamente verificadas da seção, sem
conclusão normativa. Campo vazio não equivale a FALSE nem autoriza inferência.

END

-------------------------------------------------------------------------------

ENTITY SISTEMAS_E_MEDIDAS_DE_SEGURANCA_ITEM

TYPE DOCUMENTARY_EVIDENCE

ATTRIBUTE OFFICIAL_ESCI_CODE TEXT

ATTRIBUTE PRESENTED_SYSTEM_MEASURE_DESCRIPTION TEXT

ATTRIBUTE RPCI_ORIENTATIVE_TEXT TEXT

ATTRIBUTE SOURCE_LOCATION TEXT

DESCRIPTION

Item documental da seção "Sistemas e Medidas de Segurança". OFFICIAL_ESCI_CODE,
PRESENTED_SYSTEM_MEASURE_DESCRIPTION, RPCI_ORIENTATIVE_TEXT e SOURCE_LOCATION
são fatos brutos extraídos. O texto orientativo RPCI permanece separado e não é
regra de aplicabilidade. source_document continua obrigatório pela RDE.

END
